# DSA Lab

A collection of Data Structures and Algorithms (DSA) laboratory programs completed as part of my M.Tech in Computer Science and Engineering at VIT Chennai.

## Language

- C


## Topics Covered

- Linear Search
- Binary Search
- Arrays
- String Searching
- Majority Element
- Search & Replace
- Search Insert Position
- Median of Two Sorted Arrays
- K Closest Elements
- Recursive Binary Search
- And more...

## Development Environment

- Language: C
- IDE: Visual Studio Code
- Compiler: GCC
- Version Control: Git & GitHub

# Git Workflow

### Initial Setup (One Time)

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <YOUR_GITHUB_REPOSITORY_URL>
git push -u origin main
```

### Every Time You Complete a Program

```bash
git add .
git commit -m "Completed Lab 01 Program 01 - Linear Search"
git push
```

### Every Time You Complete an Entire Lab

```bash
git add .
git commit -m "Completed Lab 01"
git push
```

## Commit Message Examples

```
Completed Lab 01 Program 01 - Linear Search
Completed Lab 01 Program 02 - Second Occurrence
Completed Lab 01 Program 05 - Multiple Linear Search
Completed Lab 02
Fixed Program 03 edge case
Updated README
```
## Clone the Repository

To download this repository on a new system:

```bash
git clone https://github.com/YOUR_USERNAME/DSA-Lab.git
cd DSA-Lab
```

Open the project in VS Code:

```bash
code .
```

## Sync Changes

Before starting work on another computer:

```bash
git pull
```

After completing a program or lab:

```bash
git add .
git commit -m "Completed Lab 01 Program 01"
git push
```
